# SupplySense AI — Data Repository

This directory contains transactional datasets supporting the **SupplySense AI: Predictive Supply Chain Intelligence Platform**.

## Structure

- **`data/raw/`**: Contains the original `DataCoSupplyChainDataset.csv` downloaded from the official Mendeley Data repository.
- **`data/processed/`**: Contains cleaned and feature-engineered datasets generated by the Python preprocessing pipeline.

## Dataset Reference

- **Title:** DataCo Smart Supply Chain for Big Data Analysis
- **Authors:** Fabian Constante, Fernando Silva, António Pereira (2019)
- **DOI:** [10.17632/8gx2fvg2k6.1](https://doi.org/10.17632/8gx2fvg2k6.1)
- **Journal Citation:** *Data in Brief*, Vol. 25, 2019, 104083.
- **License:** CC BY 4.0
