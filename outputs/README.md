# Generated Outputs Directory

This directory stores analytical artifacts, figures, exported tables, and evaluation metrics generated by the SupplySense AI workflow and Jupyter Notebook execution.

## Directory Layout

- **`figures/`**: High-resolution static plots (PNG/SVG) visualizing EDA distributions, time-series demand forecasts, confusion matrices, and ROC curves.
- **`tables/`**: CSV and markdown summaries of model benchmark comparisons, data quality reports, product category volume aggregations, regional delay breakdowns, and inventory risk assessments.
